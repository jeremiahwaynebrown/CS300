# CS300
What was the problem you were solving in the projects for this course?

The problem I was trying to solve was building an application with menu functunality that allowed for the user to display a course list and for that list to be searchable. Project One helped determine runtime complexity of three data structures in terms of opening, reading, and printing from a file. My findings from Project One influenced the code I wrote in Project 2 as it helped me narrow down which data structure was the most efficient to use.

How did you approach the problem? Consider why data structures are important to understand.

In my analysis on the runtime complexity for the three data structures, I determined that using a binary search tree (BST) was the optimal data structure to use because an inOrder call would print the tree alphanumerically without much additional implimentation. Data structures are important to understand because some data structures that may have a similar implementation, can have drastically different runtime complexity. Properly storing data in a data structure that can be used efficiently for the application being developed can allow for better memory usage, quicker runtime, and much more.
